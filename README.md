## Current Project

### **Pathogen-Host Structural Equivalence: An Immunoinformatics Study Probing Molecular Mimicry Across Autoimmune and Neurodegenerative Disorders**

### Status: ongoing 
Pipeline fully implemented across 399 peptide pairs, 32 organisms.
AUC 0.954 | r = -0.127 | 96.7% structural confirmation rate
Full repository: molecular-mimicry-RA-pipeline
Work to be done: Expansion of dataset to include pathogens related to neurodegenrative disorders.

The pipeline currently integrates:
- Sequence homology screening
- Epitope prediction and comparison
- Structural similarity assessment
- Feature engineering for downstream predictive modeling
- Dynamic Structural Proof

Rather than isolated case studies, the goal is to build a **systematic, scalable framework** for ranking mimicry candidates across pathogens, with an emphasis on biological interpretability and model transparency.

This repository reflects my ongoing effort to move from descriptive bioinformatics toward **predictive and mechanistic modeling** in immunology.

### Current Projects on GitHub:

- Pathogen-host-mimicry-analysis

 - Reproducible immunoinformatics pipeline to identify and rank pathogen–host molecular mimicry candidates using sequence, structural, and ML-based features.

- Immune-dynamics-model

 - A minimal mechanistic ODE model simulating antigen decay and T-cell activation dynamics to demonstrate quantitative reasoning in computational immunology.
